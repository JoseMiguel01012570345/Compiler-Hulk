# HULK Compiler

The **HULK Compiler** is designed to demonstrate the principles of compiler construction, including lexical analysis, syntax analysis, semantic analysis, and code generation.

## Features

- **Lexical Analysis**: Tokenizes the input source code.
- **Syntax Analysis**: Parses tokens to validate the structure of the code.
- **Semantic Analysis**: Ensures the code adheres to semantic rules.
- **Code Generation**: Produces intermediate or target code.

## Project Structure

- **/src**: Contains the source code for the compiler.
- **/tests**: Includes test cases for validating the compiler's functionality.
- **/docs**: Documentation related to the project.
- **/examples**: Sample programs to test the compiler.

## Dependencies

To run the project, follow these steps:

1. **Install Poetry**: Poetry is a dependency management tool for Python. You can install it by following the instructions on the [official Poetry website](https://python-poetry.org/docs/#installation).

2. **Install Dependencies**: Use Poetry to install the required dependencies for the project. Run the following command in the project directory:
   ```bash
   poetry install
   ```

## How to Build and Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/hulk-compiler.git
   ```
2. Navigate to the project directory:
   ```bash
   cd hulk-compiler
   ```
3. **Navigate to the `src` Folder**: Move to the `src` directory where the main source code resides:

   ```bash
   cd src
   ```

4. **Run the Compiler**: Execute the `main.py` file to run the compiler:
   ```bash
   poetry run python main.py
   ```
